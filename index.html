ตู้ลำโพงทำมือ ระบบบ้านอัจฉริยะด้วย ESP32 และโปรแกรมเล็กๆ ที่เขียนไว้ใช้ในบ้าน ถ้ามีประโยชน์กับใคร โหลดไปใช้ได้เลยครับ

โปรแกรมแจกฟรี

กดดาวน์โหลดจะได้เวอร์ชันล่าสุดเสมอ ทุกไฟล์มาจากหน้า GitHub Releases ของผมโดยตรง

ผลงาน

โปรเจกต์ที่ทำอยู่และที่ทำเสร็จแล้ว พร้อมสเปกที่ใช้จริง

หุ่นยนต์ประสิทธิโชต

หุ่นสองล้อขนาดเท่าฝ่ามือ โครงลวดทองเหลืองบัดกรีมือทั้งตัว

  • ใช้ ESP32-C3 เป็นสมองกล สั่งงานผ่าน Wi-Fi จากมือถือ
  • จอ OLED เป็นใบหน้า เปลี่ยนสีหน้าตามอารมณ์ได้
  • วิ่งตามสั่งและหลบสิ่งกีดขวางเองได้
  • แบตลิเธียมในตัว ชาร์จผ่าน USB-C

ตู้ซับวูฟเฟอร์ 3.5 นิ้ว แบบเบสรีเฟล็กซ์

ตู้วางข้างโต๊ะทำงาน เน้นเบสนุ่มลึก ใช้ดอกโคแอกเชียล 3.5 นิ้ว

  • ขนาดภายนอก 11 × 15 × 20 ซม. ไม้ MDF 18 มม.
  • ท่อพอร์ต Ø50 มม. ยาว 100–110 มม. จูนประมาณ 68–72 Hz
  • บุโฟมซับเสียงและเสริมโครงค้ำภายใน

ระบบบ้านอัจฉริยะ ESP32 + Home Assistant

คุมไฟและเครื่องใช้ในบ้านผ่านมือถือ ค่อยๆ ขยายทีละห้อง

  • ใช้มินิพีซีลง Home Assistant เป็นเครื่องแม่ข่าย
  • บอร์ด ESP32 ขับรีเลย์ คุมไฟและปลั๊ก
  • กำลังทำ: วัดไฟทั้งบ้านด้วย CT clamp (ตัวคล้องสายวัดกระแส)

วิธีโหลดและติดตั้ง

โปรแกรมบน Windows จะมีหน้าจอเตือนตอนเปิดครั้งแรก เป็นเรื่องปกติของโปรแกรมที่แจกฟรีจากผู้พัฒนารายเล็ก

  1. กดปุ่มดาวน์โหลดระบบจะพาไปหน้า GitHub Releases ให้เลือกไฟล์ที่ลงท้ายด้วย .zip หรือ .exe
  2. ตรวจไฟล์ก่อนเปิด (ไม่บังคับ)กดลิงก์ "ผลสแกนไวรัส" ในรายการโปรแกรมเพื่อดูผลตรวจจาก VirusTotal
  3. ถ้าขึ้น "Windows protected your PC"กด More info แล้วกด Run anyway
  4. ใช้งานแล้วติดปัญหาแจ้งได้ที่หน้า Issues ของโปรแกรมนั้นบน GitHub
โปรแกรมทั้งหมดแจกฟรี ใช้ได้ทั้งส่วนตัวและแบ่งปันต่อ ไม่มีโฆษณา ไม่เก็บข้อมูลผู้ใช้ และไม่มีการรับประกันใดๆ ใช้งานด้วยความระมัดระวังครับ
